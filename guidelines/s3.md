# S3 (MinIO)

Пример исходного STG хранит файлы в S3-совместимом MinIO:

- `pkg/connections/minio` предоставляет `*minio.Client`.
- `internal/app/clients/s3` предоставляет upload/download/delete и метрики.
- `internal/app/repository/filerepo` потребляет локальный интерфейс `Store`.
- `internal/app/services/filestore` формирует ключи и выполняет use cases.
- `internal/app/router/filectrl` предоставляет HTTP API.

`create.sh` удаляет S3-пример и соответствующие tests. Перед использованием
в сгенерированном приложении создайте необходимые пакеты и подключите модули.

## Конфигурация и lifecycle

```yaml
minio:
  endpoint: localhost:9000
  access_key: ${S3_ACCESS_KEY}
  secret_key: ${S3_SECRET_KEY}
  use_ssl: false
s3:
  bucket: stg-local
```

Для локального Compose используйте учётные данные из `docker-compose.yaml`;
`use_ssl: false` соответствует локальному endpoint. Настройки deployment
выбираются по окружению.

Бакет проверяет/создаёт `s3.Client.EnsureBucket` в Fx `OnStart` клиента,
а не Grace-сервис репозитория. В исходном STG см. `internal/app/clients/s3/fx.go`.

## Контракт и интерфейсы

Текущий `filerepo.Store` объявляет:

```go
type Store interface {
    Upload(context.Context, string, io.Reader, int64, string) error
    Download(context.Context, string) (io.ReadCloser, domain.ObjectMeta, error)
    Delete(context.Context, string) error
}
```

Для фрагмента нужны imports `context`, `io`, `stg/internal/app/domain`.
`Download` получает metadata через `obj.Stat()` внутри клиента. Отдельного
публичного `Stat` в текущем client API нет. Fx-адаптер просто присваивает
`*s3.Client` локальному интерфейсу, без conversion-wrapper.

| Метод | Путь | Результат |
|---|---|---|
| POST | `/v1/files/` | Multipart field `file`; `{"data":{"key":"..."}}` |
| GET | `/v1/files/{key}` | Содержимое с metadata headers |
| DELETE | `/v1/files/{key}` | `{}` при успехе |

Для последующих запросов используйте возвращённый upload key: filestore
формирует его с UUID, а не Unix timestamp. Reader после download должен быть
закрыт потребителем; client закрывает объект при ошибке получения metadata.

## Метрики и локальная разработка

Client собирает `s3_requests_total{action,error}` и
`s3_request_duration_seconds{action}` для `upload`, `download`, `delete`.
Stat является частью download и не отдельным action.

Compose поднимает MinIO на `9000` (API) и `9001` (console). `make dev_env_up`
сначала удаляет предыдущие Compose volumes через `dev_env_down`; учитывайте это
при локальных данных. Для tests см. [Тестирование](integration-testing.md).
